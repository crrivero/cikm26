# cikm26
Micro vs. Macro Averaging for Link Prediction Evaluation in Knowledge Graphs

This corresponds to the paper: Lydia Klecan and Carlos R. Rivero. Micro vs. Macro Averaging for Link Prediction Evaluation in Knowledge Graphs. CIKM'26. https://doi.org/10.1145/3799682.3840137

Download the datasets from here: https://github.com/nari97/AugmentedKGE/tree/master/Datasets/

Download the models from here: https://drive.google.com/drive/u/0/folders/1mkjSx-kfkCaBmQnqHHVIKMvkebp4f1f- (Ranks_TopBottom)

Run main.py (before installing everything needed) to get the metric measurements.

Run ProcessMeasurements.py to get all the metrics you'd like to play with.

Run all the other files to create plots.
